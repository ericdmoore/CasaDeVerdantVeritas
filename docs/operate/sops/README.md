# SOPs — Standard Operating Procedures

*One-page, point-of-use procedures for running the greenhouse. Per [Operating Principle 2](../00-operating-principles.md), every recurring task gets a written, photographable SOP so a new volunteer is productive in 15 minutes and no knowledge lives in only one head.*

## How to use these

- **Print and laminate each SOP. Hang it at the point of use** (by the door, by the controller, by the tank).
- **Follow it top to bottom.** If a step's "what good looks like" fails, do what the *If something's wrong* box says.
- **Log it.** Every visit ends with a line in the logbook — date, who, what you did, anything odd. Continuity across rotating hands depends on it.
- **Photos beat words.** Each SOP has spots marked 📷 — add a real photo of *this* greenhouse before laminating.

## Emergency quick-reference

> **Too hot inside / high-temp alarm:** open the door and roll up the sides *before entering*; confirm vents/fans; if it's a power problem, check the battery. See [SOP-03 §Emergency](SOP-03-summer-survival.md#emergency-response).
> **Escalation chain:** alert → on-call volunteer → backup → **staff lead**. Numbers posted by the door (keep current each semester).
